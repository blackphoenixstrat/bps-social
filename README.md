# Black Phoenix Strategies — social media files

Finished, published social-media files only: Reels (MP4) and their covers (JPG/PNG).

- Purpose: give Metricool / Typefully a stable public URL to fetch media from, without touching the website's Vercel deployments.
- Layout: one folder per series and month, e.g. `blindspot/2026-10/blind-spot-01.mp4`.
- Direct link to any file: `https://raw.githubusercontent.com/blackphoenixstrat/bps-social/main/<path>`.

**Nothing else goes here.** No scripts, scene code, voiceovers, music, render pipelines or drafts — those stay in the private site repo under `production/`.
